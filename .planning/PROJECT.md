# Project Summary
Attendance Management System
A web-based platform for managing student attendance, scheduling classes, and handling user roles for an educational institution.

## Architecture
- Backend: Express/TypeScript + MySQL
- Frontend: Next.js + TailwindCSS + Shadcn UI

## Workflows
- Core workflow involves administration setting up academic years, admission batches, semesters, classes, and subjects.
- HODs and Tutors are assigned.
- Teachers mark attendance for class sessions.
- Students view their timetable and attendance.
